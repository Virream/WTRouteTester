# WTRouteTester — 战争雷霆 · 跑图线路测试器

基于战争雷霆官方 **8111 本地 HTTP 接口** 的小工具: 记录"重生后多久到达某位置"的线路,
多条对比、按绝对时间轴回放; 也可以整局**记录所有玩家的地面线路**(A/B 两队分别录一次),
用来复盘谁在什么时间走了哪条路。

> 与 [WTBlackList 黑名单助手](https://github.com/Virream/WTBlackLists) 是**两个独立程序**,
> 可以同时开、互不影响; 唯一共用的是"怎么调 8111"这套经验。

当前版本 **v1.2.0**(2026-10-24), 更新日志见 [`CHANGELOG.md`](CHANGELOG.md)。

## 下载

到 [Releases](https://github.com/Virream/WTRouteTester/releases) 下
`WTRouteTester_<版本>_win64.zip`, **解压即用**(无需安装)。

- 程序把数据写在 exe 同级的 `data\`(`routes.json` 录制的线路 + `maps\` 地图缓存);
  zip 里**不含** `data\`, 首次运行自动创建;
- 升级时把旧的 `data\` 一起拷进新目录即可, 录制内容不会丢。

## 使用说明

录制分两种模式: **单条路线录制** 与 **全局录制**。

### 单条路线录制

用来测一辆车的加速度、转弯半径、到地图某个点位的耗时等。

1. 进入对局(**自定义 / 试车场 / 实战**均可);
2. 点 **「开始录制轨迹」** 或按 **`F5`** 开始;
3. 跑完后按 **`F6`** 或点 **「结束录制轨迹」** 保存;
4. 保存后把鼠标移到地图上的**采集点**上, 左下角会浮出一个信息框, 显示
   载具型号、该点的时间、速度、转弯半径等。

**「以速度从零变化的时刻作为起始点」**: 只对单条路线生效。勾上后, 时间轴的 0 点
取"速度开始从零变化的那一刻", 也就是从**车子开始移动**时算起(而不是点录制的那一下)。

### 全局录制

录制**整局所有玩家**的地面路线, 用于战后复盘、找优势开局路线。

受 8111 API 限制, 一次只能看到**有图标**的单位(= 队友), 所以要**分两次录制**
(A 队一次、B 队一次)才能拿到整局两队所有地面单位的轨迹。
**全局录制会忽略所有空中单位**(无人机、固定翼、直升机)。

**录制时间的起点有要求**: 8111 只能观战一方, 而且时间轴以"抓到第一辆车"为 0 点,
所以两次录制必须从**同一个状态**开始。

1. 在所有玩家处于**准备阶段**(双方等待的 15 秒)时, 选中一支队伍的一位玩家 ——
   最好选**只出了一辆地面载具、死了就退**的玩家, 且**没有用分体防空**
   (分体防空一局会有好几条线, 让对轴变复杂);
2. 确保自己处于**自由视角**;
3. 点 **「A 队录制」**, 然后**什么都不要做**;
4. 回放放完返回车库、或点「重新开始」时, 录制会**自动停止**;
5. 录完在左侧找到刚录的**全局条目**, 右键 → 勾选 **「标记为 B 队录制目标」**;
6. 换到另一支队伍, 按 1~4 同样的流程录一次(这次会自动写成这个条目的 B 队)。

两次都录完后, 条目上会出现一个**感叹号**: 因为两次录制的时间轴起点有微小偏差,
且极少数路线的结尾 8111 报得不准, 需要做**对轴**与**部分路线结尾修正**。

- 点那个**感叹号** → 在弹出的界面里为 A 队、B 队各选中**刚才游戏里观战的那位玩家**
  (软件会按阵亡记录推测, 但**不保证准确**) → 确定;
- 选错了可以右键条目重新修正。

### 注意事项

- **暂不支持倍速录制**: 录制时请保证游戏回放处于 **1x**, 未来可能会支持;
- **不要随意改采样率设置**: 除非遇到稳定性问题。已知 8111 偶尔**漏报 hudmsg**,
  会导致路线修正出错; 遇到时可以试着调整采样率, 但漏报**无法 100% 消除**
  (这是 8111 的 bug);
- 8111 的数据更新速度似乎**和游戏帧数有关**: 录制时尽量保证游戏帧数**高于**你设置的采样率;
- **全局录制里的速度是推算出来的**, 已确认与实际值有偏差 —— 不要完全相信全局录制的
  速度信息(单条路线录制没有这个问题);
- 8111 **不提供转弯半径**, 单条路线录制里的转弯半径是**算法算出来的**:
  `5 M ±15%` 中的 `±15%` 是**置信度**, 数值越低, 前面算出的转弯半径越可靠。

## 主要功能

- **单条线路录制**: 25Hz 采样, 按速度配色, 可打时间标记, 算转弯半径;
- **地图与战区**: 直接取 8111 的地图图片(自动识别同图不同分辨率)、战区(A/B/C)与重生点;
  关掉游戏也能用缓存看回放; 「地图管理」里可以给地图改名、把用不到的图(比如空战图)
  勾上「隐藏」—— 只是不在左侧列表显示, 轨迹与缓存都会保留;
- **多条对比**: 侧栏按 地图 → 模式 → 版本(战区布局) → 线路 四层分组,
  眼睛图标控制显示, 选中即回放;
- **A/B 队全局录制**: 两次独立观战分别录下整局所有玩家的地面线路, 分两队按绝对时间轴
  同步回放; 支持边录边画、重录覆盖; 每条命有稳定短编号(`A27`、`B13`),
  侧栏与悬停都能看到;
- **阵亡时刻修正**: 用 `/hudmsg` 的击毁记录, 把"摄像机挂着那位玩家"的真实阵亡时刻补回来
  (一局死几次就修几条线), 阵亡处画叉、线路变暗;
- **录制叠加层**: 录制时显示实际采样率、轮询频率、点数、标记数;
- **轮询率可调**: 菜单「设置 → 轮询间隔」里, 单条录制 / 全局录制 / hudmsg 三档各自独立
  (默认 40 / 100 / 2000 ms); 界面右上角的「轮询 xx Hz」是**实际**频率;
- **GPU 画布**: 装了 `pygfx` + `wgpu` 时用 GPU 画(见 `requirements-gl.txt`),
  否则自动回退软件渲染。

## 数据来源与反作弊

只读游戏自带的 `http://127.0.0.1:8111` 本地接口,**不读取、不修改任何游戏文件**
(不碰安装目录、日志、存档), 不注入进程 —— 纯外部轮询。

## 快捷键(默认)

| 键 | 动作 |
|---|---|
| `F5` | 开始录制轨迹 |
| `F6` | 结束录制轨迹(保存) |
| `F7` | 标记当前位置 |

可在菜单「快捷键」里改; 程序不拦截按键(游戏也会收到), 建议绑游戏里没用的键。

## 从源码运行 / 打包

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt          # GPU 画布另加 requirements-gl.txt
.venv\Scripts\python route_tester.py                   # 直接运行

.\build_route_tester.ps1                               # 打包 onedir 目录版
```

打包前请**关掉正在运行的程序**, 否则 `dist\WTRouteTester\data` 被占用会中止
(脚本会保护该目录, 绝不删用户的录制数据)。
